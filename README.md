# Epic Trade

Bybit 무기한 선물용 통합 차트. 한 화면에 **추정 청산맵 + 스마트 머니 컨셉 + 엘리엇 파동**을 겹쳐 본다.
차트 엔진은 TradingView의 오픈소스 [Lightweight Charts](https://github.com/tradingview/lightweight-charts) 5.1.0, 데이터는 Bybit v5 공개 API(키 불필요).

## 실행

```
node server.js      # → http://localhost:8787
```

`index.html`을 브라우저로 직접 열어도 되지만, 브라우저가 Bybit REST 호출을 막으면(CORS) 위 서버를 쓴다. 서버는 정적 파일과 `/bybit/v5/market/*` 프록시만 제공한다.

## 기능

| 영역 | 내용 |
|---|---|
| 청산 히트맵 | 시간×가격 추정 청산 레벨. 기간 24시간~3개월 |
| 청산맵 | 현재 남은 레벨의 가격대별 막대(레버리지 티어별) + 롱/숏 누적선, 상위 밀집 구간 목록 |
| 실청산 | Bybit `allLiquidation` 스트림의 실제 청산 체결(버블 + 피드) |
| SMC | BOS / CHoCH, 스윙(HH·HL·LH·LL), 오더블록, FVG, EQH/EQL(유동성), 프리미엄/디스카운트 |
| 엘리엇 | 자동 카운트(ATR 지그재그 + 절대 규칙 검증), 수동 카운트(클릭), 무효화 레벨, 피보나치 목표 |
| 기타 | OI 보조창, 거래량, 펀딩비, 롱/숏 계정비, 과거 봉 자동 추가 로딩 |

## 반드시 알아야 할 한계

- **청산맵은 Coinglass 데이터가 아니다.** Coinglass 청산 히트맵 API는 유료이고 모델도 비공개다. 여기서는 Bybit OI 증가분을 신규 진입으로 보고 레버리지별 청산가를 계산한다(`js/liqmap.js`). 레버리지 분포(10x 30% · 25x 35% · 50x 25% · 100x 10%)와 유지증거금률 0.5%는 **가정값**이다. 금액은 절대값이 아니라 상대 비교용이며 Coinglass 화면과 일치하지 않는다.
- Bybit 한 거래소의 OI만 쓴다. Binance·OKX 포지션은 반영되지 않는다.
- OI 증가를 롱·숏 동일 비중으로 본다. 실제 진입가·레버리지는 알 수 없다.
- 실청산은 접속한 이후 체결분만 쌓인다(Bybit는 과거 청산 내역을 공개하지 않음). 브라우저 localStorage에 최근 3,000건 저장.
- 엘리엇 자동 카운트는 규칙을 통과한 후보 1개일 뿐이다. 같은 차트에 유효한 카운트는 여러 개 존재한다.
- SMC 신호는 확정봉만 사용해 리페인트되지 않지만, 스윙 피벗은 설정 길이만큼 늦게 확정된다.
- 어떤 지표도 수익성이 검증되지 않았다. 백테스트는 포함되어 있지 않다.
